BetterActivityMonitor Performance Audit

Every screen, the menu bar item and the sampler were measured and traced with Instruments' Time Profiler, before and after a round of fixes. Most of the app's CPU and memory went to things nobody could see: a ring animation that re-laid out the whole window at display refresh rate (even with the window closed), and GPU buffer pools of about 120 MB each behind an 18-point menu bar image and behind the history charts.

Machine Apple M4 Pro, 14 cores, 48 GB, two displays macOS 27.2.1 (26B131) Builds before: main @ 9b7dce2 · after: same + this audit's changes (Release, Xcode 27.2) Refresh 1 s unless noted
